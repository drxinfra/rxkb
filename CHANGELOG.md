# Изменения

## 0.1.0 — 2026-11-07

Первая версия: публичный MCP-сервер базы знаний drxinfra.ru на https://drxinfra.ru/mcp.

- Восемь инструментов только для чтения: `find_error`, `get_article`, `search_site`, `size_rx`, `size_ai`, `component_versions`, `upgrade_checklist`, `security_self_check`. Каждый ответ со ссылкой на страницу сайта и строкой, куда писать за помощью.
- База `kb.json` собирается из исходников сайта (`hack/build-kb.py`) и подхватывается сервисом без перезапуска.
- Сайзинг RX считает модель сайта (`assets/sizing.js`) во встроенном интерпретаторе JavaScript; разбор лога, поиск, железо под ИИ, самооценка и чек-лист повторены на Go и сверены с сайтом в headless Chrome (`hack/parity/site-check.mjs`, 77 проверок).
- Streamable HTTP без сессий на официальном Go SDK MCP 1.8.0: протоколы 2026-07-28 (`server/discover`) и 2025-11-25, 2025-06-18, 2025-03-26 (`initialize`).
- Лимиты частоты, одновременности, размера и времени; журнал без аргументов; systemd с изоляцией; образ из `scratch`.
